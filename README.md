## Overview

Ethos is an end-to-end autonomous driving research platform combining diffusion-based synthetic environment generation, uncertainty-driven active learning, and closed-loop vehicle trajectory prediction. By coupling high-fidelity physics telemetry from BeamNG.drive with neural world models and diffusion styling (EbSynth / DiT), Ethos enables domain adaptation, edge-case mining, and continuous model improvement without requiring millions of manual real-world miles.

---

## Core Capabilities

- Generative World Synthesis (EthosDit.py, generate_diffused_3.py): Generates photorealistic and novel driving scenarios using diffusion models and temporal keyframing.
- Active Learning Curation (active_learning_curator.py): Automated edge-case detection and interactive GUI for reviewing high-uncertainty frames flagged during closed-loop evaluation.
- Multi-Model Steering Architectures: Benchmarks and exports neural steering models ranging from lightweight temporal networks to Vision Transformers (v2, v2.2, v3, tiny_sim).
- Telemetry Collection and Replay (beamng_collect.py, beamng_playback.py): Synchronized frame and physics logging (velocity, yaw rate, wheel slip, steering angle) with deterministic replay capabilities.
- Steering Calibration and Telemetry Comparison (calibrate_steering.py, compare.py): Detailed telemetry analysis, residual error tracking, and model latency profiling.

## System Architecture

### 1. Active Learning Loop
```
+------------------+       +-------------------+       +-----------------------+
|  BeamNG.drive    | ----> |  Inference Engine | ----> |  Uncertainty Monitor  |
|  Live Simulation |       |  (Steering Model) |       |  (Entropy / Variance) |
+------------------+       +-------------------+       +-----------------------+
         ^                                                                 |
         |                                                                 v
+------------------+       +-------------------+       +-----------------------+
|  Model Retrain   | <---- | Approved Dataset  | <---- | Active Learning GUI   |
|  & Fine-Tuning   |       | Curation Buffer   |       | (active_learning_...) |
+------------------+       +-------------------+       +-----------------------+
```

### 2. Generative Domain Adaptation
1. Source Capture: Capture canonical geometric tracks and trajectories via beamng_collect.py.
2. Diffusion Synthesis: Feed keyframes into generate_diffused_3.py using conditioned prompts generated by fast_generate_prompts.py.
3. Temporal Infilling: Re-project synthesized frames across intermediate timestamps using EbSynth neural style transfer.
4. Validation: Assess steering model resilience on synthesized weather, lighting, and campus conditions.

## Setup and Installation

### Prerequisites
- Python 3.10 or higher
- NVIDIA CUDA-compatible GPU (VRAM >= 8 GB recommended)
- BeamNG.drive simulation (optional, for real-time sensor integration)

### Installation
```bash
git clone https://github.com/Convoluted-Dense/Ethos.git
cd Ethos
python -m venv .venv
.venv\Scripts\activate
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
pip install flask opencv-python numpy scikit-learn pillow matplotlib
```

## Quickstart Guide

### 1. Launch Curation & Model Dashboard
Launch the integrated Flask dashboard:
```bash
python EthosDit.py
```
Open your browser to http://127.0.0.1:5000 to inspect datasets, run scenario generations, and review telemetry.

### 2. Active Learning Curation
Review flagged frames from recent evaluation runs:
```bash
# Interactive GUI mode
python active_learning_curator.py

# Batch auto-approval mode for high-confidence edge cases
python active_learning_curator.py --auto-approve
```

### 3. Model Comparison & Benchmark
Compare steering models against ground-truth validation trajectories:
```bash
python compare.py
```
